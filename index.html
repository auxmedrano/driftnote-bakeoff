Local model comparison

Four local models, one brief, one GPU.

Qwen3.8-27B, gpt-oss:20b, and two Gemma4 variants were each given an identical prompt — build a self-contained landing page for a fictional note app called Driftnote — and run independently via direct Ollama CLI calls on the same 16GB card. No edits, no retries. What follows is what each one actually shipped.
