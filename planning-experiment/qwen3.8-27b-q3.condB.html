Why local-first

Built around the disk,
not the cloud.

The network is treated as a convenience, never a dependency. Here’s what that buys you every day.

01

Written to disk first

Every keystroke lands in a local store before anything else happens. Open, edit, search — the network is an afterthought, not a dependency.

  • 12 ms median open time
  • Works in airplane mode, forever
  • Plain Markdown sitting on disk
02

Sync that keeps every word

Driftnote merges changes with CRDTs, so two devices editing the same line both win. Conflicts resolve themselves, character by character.

  • Merge, never overwrite
  • End-to-end encrypted in transit
  • LAN sync when you’re off the grid
03

Search that feels instant

A local index, built as you type, finds anything in milliseconds — across every note, tag, and draft, even before you’re connected.

  • Full-text, entirely offline
  • Filter by tag, date, or nothing
  • One-click export, zero lock-in

FAQ

Questions, answered.

  • On your device, in a local store you can open with any file browser. Driftnote keeps a clean Markdown mirror of everything, so your source of truth is yours — the cloud, if you use it, is just an encrypted mirror.

  • Nothing changes. Everything — writing, search, history, tags — works with no connection at all. Changes queue locally and merge the moment any network appears, including a plain Wi-Fi network on another device.

  • With CRDTs — the same kind of merge engine behind collaborative editors. Edits combine deterministically at the character level, so both phrasings survive as far as the text allows. There is no “server copy wins,” ever.

  • Anytime, in one click: a folder of plain Markdown files, a zipped archive, or the raw store itself. No proprietary format, no export fee, no “contact support” — just files.

  • macOS 12+, Windows 10+, and Ubuntu/Debian 22.04+ are first-class today. iOS and Android are in open beta for Pro subscribers — same local store, same sync, smaller download.

  • Free is fully local on a single device, with manual export and import between machines. Pro is what unlocks multi-device sync, encryption in transit, and the longer version history. Your notes work the same either way.
